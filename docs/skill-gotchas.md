# Skill gotchas

One line per gotcha: the reference file it belongs in, then the fact.

- scripts/fetch_emu.py (setup.md): `fetch_emu.py gba-bios` fails with HTTP 404 (retrobios path `bios/Nintendo/Game%20Boy%20Advance/gba_bios.bin` moved, 2026-11-14); copied a SHA-1-matching gba_bios.bin from a sibling project instead.
- emulator-qa.md: the stock `watch.lua` logs one line per distinct PC, so a routine that walks a table (font blitter) shows a single address; `tools/lua/readmap.lua` logs per (pc, 256-byte page) and found the font in one run.
- platform-gba.md: Bandai GBA games may store text as 16-bit font-cell indices in Shift-JIS cell order (code = SJIS cell + 1, with a shift after lead 0x84): relsearch `--width 2` order `jis` finds it, `jp_left.py --sjis` does not.
- references/graphics.md §Survey: a plain LZ77 header scan over a GBA ROM gives ~1% header-shaped false hits in code; keeping only blocks that sit back to back with a neighbour or have a ROM pointer removed them (60 of 6069). Blocks rendered as 4bpp that show vertical stripes are u16 tables/tilemaps: "odd bytes have < 35% the distinct values of even bytes" filtered ~1000 of them (`tools/gfxsweep.py classify`).
- references/emulator-qa.md §Visual QA: in an Orca worker (no nested subagents), `codex exec -s read-only -i page.png ...` works as the read-only sheet reviewer (`tools/sweep_review.py`); calibrate it on one page with known Japanese first.
- references/emulator-qa.md §Debug tool: for an event-script engine, the fastest warp is to write a few opcodes (load map, place hero, call map init, fade in, call scene script) into spare RAM and hand that pointer to the engine's own "run event" slot (here `GS+0x1E18` + field mode 2): no flag RE needed, and any scene script runs directly. Find the opcode table first (xref one handler), then read door scripts for the map-change pattern.
- references/emulator-qa.md §emu.py: GBA games often keep their state objects in EWRAM (0x02xxxxxx) behind IWRAM pointers; a Lua range check that only accepts IWRAM pointers silently disables the whole warp (cost one debug cycle).
- references/pipeline.md §Recon 2 / emulator-qa.md §Hooks: a Lua read-hook trap test cannot see DMA reads: this game's 8x8 font is DMA'd tile by tile from `literal + code*32`, and the literal (`0x082FFFE0`, base - 32) pointed into a "free" FF run. Check code literals pointing into a candidate range as well as runtime reads.
- references/pipeline.md §Marker: a digraph scheme can serve two fonts at once when both index glyphs by the same code (here 12x12 cell = base + code*24, 8x8 tile = base + code*32): relocate both fonts and append pair glyphs at the same codes, so names drawn in both fonts need one encoding.
- references/pipeline.md §Extract: event-script sites came out duplicated (same pointer offset listed 2-4 times when scripts share code); a repointer must dedupe them or romdiff reports overlapping writes.
- references/pipeline.md §Extract: a whole-ROM byte-pattern scan for pointer opcodes (`7A <slot> <ptr>`) produced false "tail pointers" from graphics data (0xC86CCA); walking decoded scripts gave none. Script discovery needed three extra seed sources beyond the map triggers: aligned pointer tables outside the event region, scripts stored back to back after an FF (accept only if they decode to FF and hold a text/script pointer), and quest records with tag bytes before each pointer.
