Bouken-Ou Beet: Busters Road - English translation v{version}
================================================================

Unofficial fan translation of Bouken-Ou Beet: Busters Road (Game Boy Advance, Bandai, 2005).
Project page: https://github.com/minhnhattonthat/bouken-ou-beet-busters-road-en

HOW TO PATCH
1. Get your own dump of the Japanese game (no ROMs are provided, and patched ROMs must not be shared):
     {rom_name}
     size   {rom_size} bytes
     CRC32  {rom_crc}
     MD5    {rom_md5}
     SHA-1  {rom_sha1}
2. Apply {patch_name} with any BPS patcher (Floating IPS, beat, or https://www.marcrobledo.com/RomPatcher.js/).
3. The patched ROM: {out_size} bytes, CRC32 {out_crc}, SHA-1 {out_sha1}.

PLAYING
- Tested in MesenCE 2.2.1 (GBA core). Any accurate GBA emulator or a flash cart should work.
- Start from a cold boot (a fresh power-on), not from a savestate made with the Japanese ROM.
- The game saves to EEPROM; set your emulator or flash cart to EEPROM saves if it doesn't detect it.

TRANSLATION STATUS
- Dialogue, quests, menus, items, monsters, skills, system messages: translated.
- Title logo, menu labels, shop and quest headers, book labels and other graphics with text: redrawn in English.
- Prologue crawl and ending credits: translated.

KNOWN ISSUES
- In the field toolbox list, item names longer than about 13 letters run under the status panel (the Japanese game
  clips its long names the same way).
- Report anything else at https://github.com/minhnhattonthat/bouken-ou-beet-busters-road-en/issues
  (a savestate helps most).
