# r18 review - b078 b079 b080 b081 b082 b084 (voices, weapons, UI)

Note on the inputs: `tbl_voices` is the only script file with non-unique ids (24 ids x 11 entries each). The pairs
file r18.txt shows the same JP/EN 11 times per id (the last entry's), so the shout review below was done against
the real per-line pairs, `work/tl/b078.tsv` / `b079.tsv` next to their `.out.tsv`. The pairs file also shows
`ui:DDABB4` as "[FF01]days", but the out file and `script/ui.json` say "[FF01]d" (stale pairs).

### Issues

#### Critical
- voices:000-023 (all 264 entries, `script/tbl_voices.json`) - each record holds 11 different shouts (battle start x2,
  attack x3, Divine Attack x3, damage x3) - the merge wrote ONE English line into all 11 entries of an id: the
  record's last damage cry. So in battle Poala says "Ngh!!" for みんな、気をつけて！ / さっさと片付けるわよ！ / いくわよ！ ...,
  Ventura says "Ugh... uggggh...!!" for このベンチュラ様が・・・相手だ！ / ウケケケケッ！！, Shaderico "Gek!" for every
  ゲヒヒ line, and 017 / 018 / 021 say "Take that!" even for their defeat cry バカな！！ ("Impossible!!", the opposite
  beat: victim's disbelief, not an attacker's taunt). Cause: `tools/batches.py` keys entries by id (`index()`,
  `dict(rows)` in check, `fan_out` writes `out[e["id"]]`), so duplicate ids collapse to the last row; 017's last
  entry shares its JP key with 018/021, which is how 018's "Take that!" reached it. The translator's per-line work
  in `b078.out.tsv` / `b079.out.tsv` is good and complete - fix: re-merge by address (`addr`) or by (id, JP) so
  every entry gets the row whose JP it carries; then the shared-JP fan-out (e.g. くらえ！！ "Take this!!",
  フン！！ "Hmph!!") still applies. Re-generate the pairs file after the fix.

#### Important
- ui:DDABB4 - [FF01]日 "N days (left)" on the quest log 期限 row - "[FF01]d" is an abbreviation (D4: none; "5d").
  limits.py gives this in-place string 4 letters, which holds "days" exactly - suggested EN: [FF01]days, or
  [FF01] day if a space between number and word is needed and "days" won't fit with it (never "d").

#### Minor

  ruling (glossary series words), but young players read "Bronze Grave" as a tombstone; the weapon is a glaive. If the
  controller reopens it: Bronze Glaive ... Master Glaive (Slade's Silent Grave can stay as the glossary name).
- weapons:085-094 - 槌 "Mallet" next to バトルハンマー / マスターハンマー "Hammer" in the same series (descs of
  093/094 say "Mallet of ...") - per the glossary ruling, but "Mallet" sounds like a croquet toy - consider Hammer for
  the whole series (would also touch ev:1784EA / 178522 "Copper Mallet").
- weapons:166 - グリニデ変身後 - "Grineed Transformed" vs bosses:002 "Transformed Grineed" - suggested EN:
  Transformed Grineed.
- ui:DDA872 - ヤリ spear - "Pike" vs the weapon tables' 槍 "Spear" and wtypes Spear (unused string) - suggested EN:
  Spear.
- ui:DDA8B2 - 渦 - "Whirl" vs loot:027 "Whirlpool Chalice" (unused string, 4-letter room? if it fits) - suggested
  EN: Whirlpool.

  the 12 row label).
