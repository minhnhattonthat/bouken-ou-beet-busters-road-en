#### Important
- areas:028:name - ムガインの死人沼 - glossary row says the map name is "Dead Swamp" (since "Mugine's Dead Swamp" is 19 letters, over the 18 limit), and all 6 dialogue/quest lines say "Mugine's Dead Swamp" (ev:184590, 1ACAAE, 24A64A, 24EBB0, 24EC30, 24ECAE). "Mugine Dead Swamp" goes with neither. The check passes only because "Dead Swamp" is a substring. tbl_maps 063-066 use the same form. - suggested EN: Dead Swamp (and maps:063-066 the same). Or, if the controller prefers "Mugine Dead Swamp" (it matches Mugine Castle), change the glossary note to say so.
- bosses:002:name - グリニデ変身後 - "Transformed Grineed" here, but weapons:166 name/menu (same JP) is "Grineed Transformed". One boss, two spellings. - suggested EN: Transformed Grineed here, and set weapons:166 name/menu to the same.
- loot:019:name - ムスリー荒野の植物 "Musley Wasteland plant" - EN "Musley Wasteland" drops "Plant", so the item is named after the area. Every other plant in the series is "<Area> Plant". "Musley Wasteland Plant" is 22 letters (over 20), and "Musley Plant" is already taken by loot:021 (Mountains). Musley is the only 荒野 area. - suggested EN: Wasteland Plant
- wtypes:005:name - 槌 - type label "Hammer", but the 槌 weapon series is "Bronze Mallet ... B-Metal Mallet" (weapons:085-092, and the descs say "Mallet made of ..."), followed by Battle Hammer / Master Hammer. So the same series word appears under two names. - suggested EN: keep "Hammer" and rename weapons:085-093 desc/names from Mallet to Hammer (Bronze Hammer ... "Rare Metal Hammer" = 17, fits 20). Or else make the type "Mallet".
- wtypes:008:name - 鉄球 - this type covers the 鎖球 weapons, which are named "Bronze Flail ... B-Metal Flail" (glossary: 鎖球 = Flail, weapon type "<Metal> Flail"). A player sees type "Iron Ball" on a Bronze Flail. The moves "Iron Ball Form/Snare" (Saiga transformations) can keep "iron ball". - suggested EN: Flail
